# BlockSade

Taivaalta sataa palikoita

## Ominaisuudet

* Palikkasateen käynnistäminen ja pysäyttäminen
* Asetusvalikko
* Äänien kytkeminen päälle ja pois
* Palikkojen syntymisnopeuden muuttaminen

## Vaatimukset / Suositukset

* Minecraft 1.21.5+
* Paper
* Java 21

## Komennot

| Komento                | Kuvaus                  |
| ---------------------- | ----------------------- |
| `/blocksade`           | Näyttää ohjeet          |
| `/blocksade start`     | Käynnistää blocksateen  |
| `/blocksade stop`      | Pysäyttää blocksateen   |
| `/blocksade info`      | Näyttää plugarin ohjeet |
| `/blocksade asetukset` | Avaa asetusvalikon      |

## Asennus

1. Lataa lisäosan JAR-tiedosto.
2. Siirrä tiedosto palvelimen `plugins`-kansioon.
3. Käynnistä palvelin uudelleen.
Tai käännä source koodi
